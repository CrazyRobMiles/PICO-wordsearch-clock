
## Building a clock

You can build your own version of the clock. The simplest way to do this is to use the supplied case designs and **clockface.json** file. This will produce a clock with the wordsearch arrangement you can see above. If you want to make your own wordsearch design you can do this, but it is slightly more complex.

If you build the alarm clock you'll need to set up a MicroSD card with the sound samples to be used for the alarms.
